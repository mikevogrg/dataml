# Presentation source (13 slides)

The slide deck lives online (see `../docs/M5_DELIVERABLES.md`); open it there to present, or download .pptx / PDF from its menu.
This folder is a backup of its source: `deck.json` (slide order), `deck.css` (shared styles) and `slides/*.html` (one file per slide, with timed speaker notes in each `<aside>`). These files are not directly openable in PowerPoint. The speaker notes are the talk script: read them in the HTML files, or use the timing table in `../docs/DEMO_SCRIPT.md`.
