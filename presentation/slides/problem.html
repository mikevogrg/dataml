THE PROBLEM

Bad sensor data leads to bad decisions

Spike

One reading jumps far from its neighbours in time

Stuck

A sensor freezes on one value that still looks plausible

Bias

Readings sit a fixed amount too high or too low

Drift

Error grows slowly, so each reading looks almost normal

Impossible

Values like 122 °C in an office, a real Intel Lab reading

Missing

Dropped packets leave holes in the stream
