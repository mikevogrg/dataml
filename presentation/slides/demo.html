Then open results/before_after_humidity.png

4:30–8:30. Run the four commands in order. 1) simulate makes a labelled network. 2) clean runs the offline pipeline and prints how many readings were flagged per channel. 3) explain shows, for one sensor, which readings were changed and the reason (range, hampel, stuck, spatial, iforest). 4) the stream replay prints faults and repairs one by one next to the true value. Finish by opening the before/after picture. Backup plan: if anything fails, show results/before_after_humidity.png and results/report.md, which are already generated. Rehearse once beforehand.
